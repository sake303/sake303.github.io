Effective September 27, 2026. Operator: Seokhee Lee. Contact: seokhee@bd360.co.

Purpose and scope

This is a private, self-hosted evaluation of the Open Wearables Oura integration for one authorized Oura account. Its purpose is to observe when one newly completed sleep session becomes visible through the existing scheduled REST pull, Open Wearables API, and Sleep screen. It is not offered to other users.

Data collected and used

With the account holder's authorization, the application requests Oura's Personal and Daily scopes. These scopes can include account information and daily health records, including sleep data. Open Wearables stores the OAuth connection and retrieved records in a dedicated local database. The operator also keeps private timing observations and a session identifier needed to compare the same record across the Oura API, Open Wearables API, and Sleep screen. The data is used only for this evaluation.

Storage and disclosure

The application runs in a dedicated local Open Wearables environment controlled by the operator. Oura supplies the authorized data to this environment. The operator does not sell the data or publish credentials or raw health records. A public GitHub issue may contain the experiment's status and timing conclusions, but not personal health payloads or credentials. The local service is not offered as a public data service.

Retention and deletion

The local connection, retrieved records, and private observations have no automatic expiration period. The operator retains them while the evaluation and its review require them, then manually revokes the connection and deletes the local Oura provider data and private observations when they are no longer needed. The account holder can request deletion at any time at the contact address above. Revoking access in Oura stops future authorized access but does not by itself delete records already stored locally; contact the operator to request deletion of those records.

Choices and questions

The account holder may revoke access through Oura's connected-app controls. For access, correction, or deletion requests concerning the local copy, email seokhee@bd360.co.
