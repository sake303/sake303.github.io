Which wearable should you connect to your agent: Oura or WHOOP?

This is a decision guide for people who want to connect their sleep and recovery data to an agent:

  • Whether you can access the data through an API or export
  • How much data latency there is
  • How complex the auth flow is
  • Whether you can keep this pipeline running day to day

Build log

The WHOOP flow is in HealthMes PR #157, still open for review. I wrote about the dogfood run and the Signal Guide follow-up on X.

A code review caught a small edge case: manual and Manual could create two records for the same source.

The fix is small. It made me stop and look at what I'm actually building here. For now, it's a narrow WHOOP retrieval flow. A broader wellness platform is a different project, and I don't have the evidence for it yet.

This was one dogfood run in my Product to Build to Dogfooding to Public loop. It worked that day. The PR still has open review comments about identity, revisions, time boundaries, and provenance, so I'm treating this as a build note, not proof that one device wins.
