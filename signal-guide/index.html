Current note

On August 20, I asked Codex the same question. HealthMes checked my WHOOP Recovery and the current day's Cycle strain, then sent the answer through Hermes to Telegram. If the data was stale or unclear, it held off.

One run is not a verdict on Oura or WHOOP. But it made the earlier Hermes issue concrete: even with healthy provider data, the agent can only help if it gets through the runtime.

The decision table

  • Getting the data out, and whether there is an API
  • How fresh the data is when the workflow runs
  • What it takes to connect HealthMes
  • Price, comfort, and battery

I only look at the app when it changes the agent workflow: setup, consent, export, or recovery.
