SG

I'm using Oura and WHOOP in my own agent-assisted sleep and recovery workflow. SG is the guide I'm making from those notes.

I'm using both and noting what gets in the way: getting the data out, checking how fresh it is, connecting HealthMes, and then the boring real-life stuff: price, comfort, and battery.

The part I keep coming back to starts after the wearable leaves my wrist. Can the agent fetch the data, tell whether it is current, and put it where it needs to go?

Current note

HealthMes has the actual-sleep Calendar preview again. Hermes had prepared two Calendar blocks, but the HealthMes provider was stale. There was no fallback write, so the Calendar stayed unchanged.

That made the comparison less abstract. Approval was not the issue. Before an agent writes, the provider has to be live. Afterwards, I need to be able to read the result back where the workflow expects it.

What I'm checking

  • Getting the data out, and whether there is an API
  • How fresh the data is when the workflow runs
  • What it takes to connect HealthMes
  • Price, comfort, and battery

I only look at the app when it changes the agent workflow: setup, consent, export, or recovery.
