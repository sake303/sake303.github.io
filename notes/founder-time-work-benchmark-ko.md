# 내가 잘하고 싶은 일

현장에서 사람들이 어떻게 일하는지 직접 보고, 어떤 문제를 누구와 풀지 정하는 일을 잘하고 싶습니다.

[Clay 공동창업자 Varun Anand](https://review.firstround.com/podcast/inside-clays-unconventional-path-to-1-25b/)를 벤치마킹합니다. 그는 고객이 실제 업무를 Clay로 처리하는 모습을 보며 어디서 막히는지 찾았고, 발견한 문제를 엔지니어에게 전달했습니다.

저도 현장 대화와 문제 선택은 직접 하고, 에이전트에는 대화 준비와 후속 정리, 구현을 맡기려 합니다.
