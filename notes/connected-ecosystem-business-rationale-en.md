## Business model

I'm using Terra's pricing structure as a reference. The plan is a base subscription with an included allowance and a separate charge for usage above it.

Terra's Unified API Quick Start starts at $499 a month on monthly billing, or the equivalent of $399 a month on annual billing, with 100,000 credits included each month. An active connection between one user and one data source uses 200 credits per month. Events above 400 per connection per month also use credits. Terra bills separately for credits used above the monthly allowance. [Terra pricing](https://tryterra.co/pricing)
